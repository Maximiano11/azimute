Documentação da API

A API do Azimute expõe inteligência de viagem em tempo real para parceiros de turismo: roteiros confiáveis, índice de confiança por destino, alertas oficiais e relatos de viajantes, análise preditiva sazonal e webhooks anti-golpe.

Base URL: https://api.azimute.app/v1 · Formato: JSON · CORS: habilitado

Autenticação

Todas as requisições exigem uma API key enviada no header Authorization.

Authorization: Bearer sk_live_xxx

Chave de demonstração disponível: sk_demo_azimute_5f3a9c0b.

Roteiro confiável

GET/v1/route/safe

Retorna o roteiro com maior score de confiança para viajantes, ponderando alertas oficiais de turismo, relatos da comunidade, iluminação e horário.

ParamTipoDescrição
from[lat,lng]Origem (hospedagem ou ponto atual)
to[lat,lng]Atração ou destino
profilestringwalk, bike, transit, tourist
timeISO8601Horário do passeio (default: agora)

Confiança por destino

Retorna polígonos de bairros/destinos turísticos com score e tendência em tempo real.

  ],
  "updated_at": "2026-04-24T22:00:00Z"
}

Alertas de turismo

GET/v1/incidents

Lista alertas oficiais de turismo + relatos de viajantes dentro de uma bbox.

GET /v1/incidents?bbox=-23.57,-46.68,-23.54,-46.63&since=24h&category=tourist_scam

Índice de Confiança Azimute (ICA)

GET/v1/ica

Score composto que reflete a confiabilidade de um destino para viajantes, com três pilares: fontes oficiais de turismo, comunidade de viajantes e análise preditiva sazonal.

{
  "ica": 78,
  "classification": "bom",
  "pillars": {
    "official_sources": { "score": 0.82, "active": 27, "last_sync": "há 12s" },
    "community_validation": { "score": 0.74, "validations_24h": 184 },
    "predictive_model": { "score": 0.71, "confidence": 0.88 }
  },
  "forecast_2h": [
    { "t": "+30min", "risk": 0.22 },
    { "t": "+60min", "risk": 0.27 },
    { "t": "+120min", "risk": 0.35 }
  ]
}

Webhooks

POST/v1/webhooks/alerts

Receba alertas em tempo real em uma URL sua. Cada entrega é assinada com HMAC SHA-256 via header X-Azimute-Signature.

Eventos disponíveis: tourist_scam, consular_advisory, community_validated, ica_drop, seasonal_alert.
{
  "event": "ica_drop",
  "region": "sp-paulista",
  "ica_before": 78,
  "ica_after": 64,
  "triggered_at": "2026-04-14T22:03:11Z"
}
