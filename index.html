                  🔍 O que coletamos

                  • Localização (apenas durante uso ativo)
                  • Relatos voluntários
                  • Preferências de perfil

                  🤝 Com quem compartilhamos

                  • Órgãos oficiais (apenas dados agregados, anonimizados)
                  • Parceiros via API (sem PII)
                  • Comunidade (apenas o que você publicar)

                  ✋ Seus direitos

                  • Exportar seus dados
                  • Apagar sua conta
                  • Revogar consentimento
                  • Corrigir dados incorretos

                  🔒 Segurança dos dados

                  • Auditoria trimestral
                  • DPO disponível: dpo@azimute.app
